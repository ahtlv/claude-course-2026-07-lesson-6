# Skill: markitdown

## Зачем

Read по умолчанию превращает каждую страницу PDF в картинку и параллельно вытаскивает из
неё текст — платишь токены дважды за одно и то же. `markitdown` (инструмент Microsoft)
конвертирует файл в обычный текст заранее, и тогда Read можно не трогать вовсе: работаешь
с текстом на выходе `markitdown`.

## Когда применять

Перед чтением, резюмированием, извлечением данных или ответом по содержимому:
`.pdf`, `.docx`, `.pptx`, `.xlsx`, `.xls`, а также ссылка на YouTube-видео (тянет субтитры).
Обычные текстовые файлы и код (`.md`, `.txt`, `.py`, ...) не трогать — там нечего
конвертировать, Read справляется без потерь.

## Как выполнить

1. Проверь, установлен ли `markitdown`:
   ```bash
   command -v markitdown
   ```
2. Если команды нет — поставь один раз (нужен Python 3):
   ```bash
   pip install --quiet "markitdown[all]"
   ```
   Если `pip` не найден: на macOS/Linux — `python3 -m pip install --quiet "markitdown[all]"`;
   на Windows — `python -m pip install --quiet "markitdown[all]"` (если и `python` не
   найден, поставь Python с python.org или `winget install Python.Python.3.12`, затем
   повтори).
3. Сконвертируй файл или ссылку в текст:
   ```bash
   markitdown "<путь_к_файлу_или_URL>"
   ```
4. Работай дальше с текстом из вывода команды — не открывай исходный файл через Read.

## Пример

Пользователь: «изучи этот PDF и вытащи условия договора» → сначала
`markitdown contract.pdf`, и уже по тексту из вывода искать условия договора, не по
самому PDF.
